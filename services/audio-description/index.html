CONTENT INCLUSION

The soundtrack doesn’t always
tell the whole story.

A product feature shown without explanation. An instruction that appears only on screen. A change in expression that shifts the meaning. Audio description brings essential visual information into the listening experience.

Make important details understandable.

Help viewers follow actions, settings, on-screen text, and other details that the original audio does not communicate.

Design for more ways of experiencing video.

Consider blind and low-vision viewers when planning the content, its narration, and the player used to deliver it.

Start with the content and the target.

Review what the audio already conveys before deciding whether integrated, standard, or extended description is appropriate.

TWO COMPLEMENTARY LAYERS

CC

Captions make audio readable.

Speech and meaningful sounds become synchronized text.

AD

Description makes visuals audible.

Important visual information becomes narration.

Audio description complements captions. Each addresses a different part of the experience.

Where the standards fit

WCAG 1.2.5 addresses audio description for prerecorded synchronized media at Level AA. Separate description may not be needed when the original audio already communicates the relevant visual information. The content, applicable standard, and publishing context determine the work.

SCRIPT. VOICE. TIMING.

Good description is carefully made.

Scriptwriting with context

Identify the visual information that matters, then write concise descriptions around the dialogue, content, and intended audience.

Narration with a natural fit

Coordinate clear delivery, pronunciation, tone, and pacing. Confirm voice and language requirements before production.

Timing that respects the story

Place narration in available audio space, balance the mix, and choose a different delivery approach when those gaps are insufficient.

STANDARD & EXTENDED DESCRIPTION

Choose the space
your story needs.

The right format depends on how much essential visual information needs to be described and how much room the original soundtrack leaves.

STANDARD AUDIO DESCRIPTION

Work within the existing pauses.

Descriptions fit between dialogue or other important audio. The video continues on its original timeline.

EXTENDED AUDIO DESCRIPTION

Create room for essential detail.

A separate version or supported player pauses the visual sequence to allow a longer description, then continues the video.

Planning a new video?

Build important visual information into the main narration where possible. Integrated description can make the content clearer from the start.

WCAG 1.2.7 addresses extended audio description at Level AAA when pauses are insufficient. Read W3C’s explanation.

AUDIO DESCRIPTION FAQ

Useful answers.
A clearer production brief.

What is audio description?

Audio description is narration of important visual information that is not already conveyed by the soundtrack. It can describe actions, on-screen text, settings, and other details needed to understand a video.

Is audio description required by law?

Requirements depend on the content and the laws or standards that apply. WCAG Level AA includes audio description for prerecorded synchronized media under criterion 1.2.5. The original soundtrack may already provide the necessary visual information. EqualAccess. can review the technical requirements; qualified counsel should advise on legal applicability.

What is the difference between standard and extended audio description?

Standard description fits into available pauses in the original audio. Extended description adds time by holding the video while narration provides essential information. The content, available audio space, target standard, and publishing platform determine the appropriate approach.

How long does it take?

Timing depends on video duration, content complexity, voice or language requirements, approvals, and the output formats. We agree on the schedule after reviewing the material. For an urgent project, discuss the deadline before booking production.

Can you handle live events or webinars?

This service focuses on prerecorded content, including recorded webinars. Live description is a separate production requirement. Share the event format and timing so we can confirm whether support is available and what it would involve.

Do you also provide captions and transcripts?

A narration script or transcript can be included in the agreed package. Captions are a separate accessibility need and are not replaced by audio description. If you need captioning or a full descriptive transcript, include it in your brief so availability and scope can be confirmed.

How do I integrate the description with my video?

Depending on the player, the output can be a separate described video or a selectable audio track. A timed text description file needs explicit player support; it is not a recorded narration track. We agree on the format and any integration assistance before delivery.

Can you produce description in multiple languages?

Tell us the required languages, pronunciation needs, and audience. Language and voice availability are confirmed during scoping, along with translation review, cost, and production timing.
