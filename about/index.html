HOW WE APPROACH THE WORK

Understandable.
Fixable. Verifiable.

01HUMAN

Human testing where software cannot answer the question.

Tools help find detectable technical issues. Many barriers depend on context, interaction, keyboard behavior, screen-reader output, and whether someone can complete a task. We use human evaluation where judgment is required.

02FIX

Fix the underlying problem.

A report should lead somewhere. When remediation is part of the engagement, we work in the website itself. The aim is a better experience, beyond a scanner score or accessibility widget.

03VERIFY

Verify before calling something fixed.

A code change does not automatically mean a barrier has been resolved. Relevant fixes are retested using the method appropriate to the original problem.

04BE CLEAR

Be clear about what we cannot control.

Third-party apps, embedded services, and platform restrictions can create barriers outside your direct control. We document those limitations and help determine realistic next steps.

ACCESSIBILITY IS WORK

Different barriers need
different solutions.

There isn’t one line of code that solves every accessibility problem. The method should fit the barrier, followed by appropriate verification.

Keyboard interaction
JavaScript behavior and focus management.
Inaccessible forms
Labels, instructions, validation, and error handling.
PDFs and documents
Structure, reading order, and meaningful text alternatives.
Video content
Captions, audio description, or both, depending on the content.
Third-party integrations
Vendor coordination or an alternative implementation.

Understand the barrier. Use the right method. Verify the result.
